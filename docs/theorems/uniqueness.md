# Uniqueness Theorem

## Statement

For each query family `Q`, determine whether the fixed point is unique:

```text
|Fix(F_Q)| = 1 ?
```

## Alternative Forms

If uniqueness fails, the fixed points may instead form:

- a lattice
- an equivalence class of representatives
- multiple basins with the same semantic quotient

## Operational Interpretation

Uniqueness is measured by basin cardinality and representative variance.

## Measurement Predicate

The experimental harness should report:

- number of distinct terminal roots
- number of terminal basins
- within-basin representative entropy
