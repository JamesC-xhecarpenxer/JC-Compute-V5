# Knowledge Compression Theorem

## Statement

Compression is information preservation plus representation reduction.

Formally:

```text
Query(S) = Query(Compress(S))
```

while:

```text
|Compress(S)| << |S|
```

## Interpretation

UniStack is not trying to minimize all data.

It is trying to preserve meaning while reducing representation.

## Status

This is the central theorem UniStack must satisfy to be considered a knowledge-compression substrate.
